# CopilotKit LangGraph Generative UI Application

A Next.js frontend that displays visualizations generated by a LangGraph agent.

## Quick Start

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

Make sure the LangGraph backend is running:
```bash
cd ..  # Go to deep-agent-v2 directory
uv run langgraph dev
```

## Key Features

- **Plot Display**: Renders matplotlib plots generated by the agent
- **Tool Result Rendering**: Uses `useRenderToolCall` to display backend tool results
- **Image API**: Serves images from `/tmp/plots` via `/api/images/[filename]`

## Environment Variables

Copy the template and fill in your values:

```bash
cp .env.local .env
```

Then edit `.env` with your actual values:

```bash
# LangGraph deployment URL (local development)
LANGGRAPH_DEPLOYMENT_URL=http://localhost:2024

# LangSmith API key (required for LangGraph agent)
LANGSMITH_API_KEY=your_langsmith_api_key_here
```

**Note:** `.env.local` is a template file. Create `.env` with your actual credentials - it's gitignored for security.
